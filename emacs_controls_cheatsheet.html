Selection / Mark

Physical KeysAction
Ctrl+SpaceSet mark / begin selection
Ctrl+gCancel selection or current command

Note: macOS may use Ctrl+Space for input source switching. Disable or change that in:


System Settings -> Keyboard -> Keyboard Shortcuts -> Input Sources
